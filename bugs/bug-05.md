# BUG-05: Буруу JSON биетэй POST хүсэлтэд 400 биш `200 OK` буцааж, «OK» гэж хариулна

Орчин:  Уншлагын жагсаалт v2.0, curl 8.x, macOS 26.6.2, 2026-10-20
Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Терминалд дараах командыг ажиллуулна — бие нь JSON огт биш:

```
curl -i -X POST localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d 'ene bol JSON bish'
```

2. Хариуны эхний мөр (статусын мөр) ба биеийг уншина.
3. Хоёр дахь хувилбар — JSON-ы синтакс хаагдаагүй:

```
curl -i -X POST localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d '{"title":"A","author":"B",'
```

Хүлээгдэж байсан: Спецификацийн дүрэм 8 — «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана».
Бодит үр дүн:     Хоёр тохиолдолд ч `HTTP/1.1 200 OK` буцаж, бие нь `{"result":"OK"}` байна. Сервер парс хийж чадаагүй биеийг амжилттай гэж хариулна.

Ноцтой байдал: Major — буруу хүсэлтийг «OK» гэж хариулснаар клиент програм алдаагаа мэдэхгүй өнгөрнө. Хэрэглэгчийн талаас хадгалагдсан гэж ойлгогдох ч өгөгдөл үүсэхгүй — чимээгүй алдаа нь тод алдаанаас илүү аюултай.
