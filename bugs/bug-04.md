# BUG-04: Шаардлагатай талбар хоосон байхад ном нэмэгдэж, алдааны мессеж гарахгүй

Орчин:  Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.85, macOS 26.6.2, 2026-10-20
Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

### A. Хэрэглэгчийн интерфэйсээр

1. http://localhost:3000 хаягийг нээнэ.
2. Гарчиг талбарт `Software engineering` гэж бичнэ.
3. Зохиолч талбарыг ХООСОН орхино.
4. Он талбарт `2005` гэж бичнэ.
5. «Нэмэх» товчийг дарна.

### B. API-аар (терминал)

```
curl -i -X POST localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d '{"title":"Book","author":"","year":1999}'
```

Хүлээгдэж байсан: Спецификацийн дүрэм 1 — «Гарчиг, Зохиолч, Он гурван талбар бүгд заавал бөглөгдсөн байх ёстой; дутуу бол ном нэмэгдэхгүй, ойлгомжтой алдааны мессеж харагдана». UI-д алдааны мессеж гарч, мөр нэмэгдэхгүй; API `400` буцаах ёстой.
Бодит үр дүн:     A — «Ном нэмэгдлээ» гэсэн АМЖИЛТЫН мессеж гарч, зохиолчгүй мөр хүснэгтэд нэмэгдэнэ. B — `HTTP/1.1 201 Created`, бие нь `{"result":"OK","id":10}`; ном үүснэ. Аль ч түвшинд алдааны мессеж гарахгүй.

Ноцтой байдал: Major — спецификацийн шаардлагатай талбарын дүрэм UI болон сервер хоёр талдаа хэрэгжээгүй. Үүний улмаас мэдээлэл дутуу бичлэгүүд санд хуримтлагдана.
